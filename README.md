## 🚀 Deployment Guide

### Step 1 — Push to GitHub (Two Repos or One Mono-repo)

```bash
# Option A: Two separate repos (recommended)
cd backend  && git init && git add . && git commit -m "init" && git remote add origin <BACKEND_REPO_URL> && git push -u origin main
cd frontend && git init && git add . && git commit -m "init" && git remote add origin <FRONTEND_REPO_URL> && git push -u origin main
```

---

### Step 2 — Deploy Backend on Render

1. Go to **[render.com](https://render.com)** → New → **Web Service**
2. Connect your **backend** GitHub repo
3. Set:
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `gunicorn app:app --bind 0.0.0.0:$PORT --workers 2 --timeout 120`
   - **Environment:** Python 3
4. Add Environment Variables:
   ```
   JWT_SECRET_KEY   = <generate a long random string>
   DATABASE_URL     = (auto-filled if you add a Postgres database)
   ```
5. Add a **Free Postgres database** under Render dashboard → Databases
6. Link the database to the web service (copy the Internal Connection String into `DATABASE_URL`)
7. Click **Deploy** ✅

> **Note:** Free Render instances spin down after 15 min of inactivity. The first request may take ~30s to wake up.

---

### Step 3 — Deploy Frontend on Vercel

1. Go to **[vercel.com](https://vercel.com)** → New Project
2. Connect your **frontend** GitHub repo
3. Framework Preset: **Create React App**
4. Add Environment Variable:
   ```
   REACT_APP_API_URL = https://your-render-service.onrender.com
   ```
   (copy the exact URL from Render after deploy)
5. Click **Deploy** ✅

## 📊 How the Prediction Works

The predictor in `predictor.py` uses **yfinance** to fetch 2 years of historical OHLCV data, then computes:

| Signal | Description |
|--------|-------------|
| **Linear trend** | Slope of last 30 days' closing prices |
| **RSI (14)** | Relative Strength Index — overbought zones ideal to sell |
| **MACD** | Moving Average Convergence/Divergence histogram |
| **Bollinger Bands** | Price near upper band = potential sell zone |
| **MA7 / MA21 crossover** | Golden cross for bullish trend |
| **Weekday seasonality** | Historical avg return by day of week |

Each of the next 30 trading days is scored (0–100) and the **top 5** are returned with:
- Projected price
- Estimated return %
- Estimated profit/loss
- Confidence score
- Signal summary
